GAGAL  5a kegagalan di server tidak membocorkan detail database ke pengguna  -> respons='{"status":"error","pesan":"Gagal menyimpan: SQLSTATE[45000]: <<Unknown error>>: 1644 RAHASIA_SQL_DETAIL tb_log' bocor=['RAHASIA_SQL_DETAIL', 'SQLSTATE', 'tb_log_aktivitas']

LOLOS  5e halaman 404 tidak membocorkan jejak kode  -> HTTP 404; bocor=[]
GAGAL  5f .env.example berisi default aman: APP_DEBUG=false (komentar tidak dihitung)  -> nilai sekarang=['APP_DEBUG=true']
LOLOS  5g tidak ada kode debug (dd, dump, var_dump, phpinfo) tertinggal
LOLOS  5h password akun demo tidak tertulis di kode seeder (dibaca dari .env)
